# ピンボール
スペースキー長押しでためる
離したらボール発射
Vキーで左パドル操作
Bキーで右パドル操作

制作時間　
5時間

ルール　
ボールを跳ね返してスコアを稼ぐ

# 物理パズル
制作時間　
3時間

ルール　
ボールをクリックしてドラッグすると引っ張ることができます。左方向に引っ張った状態でマウスを離すとボールを発射できます。
右方向に引っ張った状態で離すとボールの位置をリセットして引っ張りなおせます。
緑のオブジェクトが地面に着くと星を獲得できます。

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

# 3DFPS
制作時間　
3時間

ルール
